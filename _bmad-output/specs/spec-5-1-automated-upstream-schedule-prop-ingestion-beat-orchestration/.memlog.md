- (capability) CAP-1: Upstream Schedule and Two-Way Prop Polling -- Worker fetches upcoming NFL and NBA events, teams, and two-way player prop markets from PARLAY_API_BASE_URL with Bearer PARLAY_API_KEY.
- (capability) CAP-2: Deterministic Local Seed Slate Fallback -- When PARLAY_API_KEY is missing or placeholder or upstream HTTP fails or returns 0 upcoming games, worker generates a deterministic multi-sport NFL/NBA slate anchored dynamically to datetime.now(UTC) across today, tomorrow, and weekend windows.
- (capability) CAP-3: Idempotent PostgreSQL Upsert and Commenced Transition -- Worker upserts Team, Event, and devigged PlayerProp rows by external_provider_id and transitions SCHEDULED events with commence_time <= now_utc to COMMENCED.
- (capability) CAP-4: End-to-End Feed Sync and 30-Second Celery Beat Orchestration -- Celery task parlaypal_worker.sync_live_slate runs every 30s in beat_schedule to devig props, update hit rates and weather, refresh presets:feed:* and markets:browser:* (45s TTL), and publish OddsDeltaFrame ticks on odds:feed:{sport_key}.
- (constraint) Enforce AD-1 service isolation (all HTTP polling and devigging in services/worker), AD-2 45-second Redis TTL warmed by 30-second Beat schedule, AD-4 Power+Multiplicative devigging and >10.0% EV SUSPECT_STALE_LINE circuit breaker, Decimal odds >= 1.01, UUID v4 PKs, provider-prefixed external_provider_id, and ISO 8601 UTC timestamps.
- (decision) Fallback triggers automatically on missing/placeholder PARLAY_API_KEY, httpx transport/timeout/HTTP error, or empty upstream event list so local development never starves Redis into static UI fallbacks.
